# Personal Catalog UI Design Study

Conceptual visual studies for the Personal Catalog public demo, showing light and dark directions at desktop and mobile sizes. The images predate the typography decision and do not reproduce the selected typefaces precisely.

## Images

- `desktop-light.png` — light theme, desktop concept
- `mobile-light.png` — light theme, mobile concept
- `desktop-dark.png` — dark theme, desktop concept
- `mobile-dark.png` — dark theme, mobile concept

## Scope

These images were generated as design references. They explore an editorial catalog layout, warm charcoal and paper surfaces, and muted teal accents. Product names, product imagery, and some interface details are illustrative. The images are not screenshots and do not establish approved final colors, copy, assets, or implementation behavior. Refer to the project specification and design guidelines for current requirements.

The selected public-demo typography is Newsreader for editorial headings and prominent product titles, paired with Source Sans 3 for interface text. See `docs/design/PUBLIC_BRAND.md` for the current proposal.
